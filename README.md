# 📊 Sales Report 2020 – Power BI Dashboard

## 📌 Project Overview

This project is an interactive sales dashboard built using Microsoft Power BI to analyze business performance throughout 2020.

The dashboard provides a comprehensive view of sales across different branches, countries, product categories, and time periods, helping transform raw data into meaningful business insights.

## 🎯 Project Objectives

- Evaluate overall sales performance.
- Identify top-performing branches and countries.
- Analyze product category and subcategory sales.
- Monitor monthly and quarterly sales trends.
- Identify business performance patterns.

## 🛠️ Tools & Technologies

- Microsoft Power BI
- Power Query (Data Transformation)
- DAX (Data Analysis Expressions)
- Data Visualization
- Interactive Dashboard Design

## 📈 Key Performance Indicators

| KPI | Result |
|---|---:|
| Total Sales | 458M |
| Q1 Sales | 111M |
| Q2 Sales | 115M |
| Q3 Sales | 119M |
| Q4 Sales | 114M |

## 📊 Dashboard Components

**1. Branch Analysis**
- Sales distribution across different branches.
- Comparison of branch performance.

**2. Geographical Analysis**
- Sales performance by country.
- Comparison between different markets.

**3. Product Analysis**
- Sales by product category.
- Sales by product subcategory.
- Identification of top-performing categories.

**4. Time Analysis**
- Monthly sales trends.
- Quarterly sales comparison.
- Yearly sales performance.

## 💡 Key Business Insights

- Total sales reached 458M in 2020.
- Q3 achieved the highest quarterly sales with 119M.
- Q1 recorded the lowest quarterly sales with 111M.
- Russia generated the highest sales among the displayed countries.
- Electronics accounted for the largest share of product category sales.
- Branch K recorded the highest sales among the displayed branches.


## 🏁 Conclusion

This project demonstrates how Power BI can be used to analyze sales data, visualize business performance, and generate actionable insights.

The dashboard helps businesses understand sales trends, evaluate performance across different dimensions, and make informed decisions.
